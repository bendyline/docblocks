# Support

For help with DocBlocks, bug reports, and feature requests:

- Search the [documentation](README.md) and
  [existing GitHub issues](https://github.com/bendyline/docblocks/issues) first.
- If the issue has not already been reported,
  [open a GitHub issue](https://github.com/bendyline/docblocks/issues/new).
- If you cannot use GitHub or the matter should not be public, email
  [support@bendyline.com](mailto:support@bendyline.com).

Please include the DocBlocks surface and version, operating system, steps to
reproduce the problem, expected and actual behavior, and any useful logs or
screenshots. Remove passwords, access tokens, private documents, and other
sensitive information before sharing anything publicly.

Potential vulnerabilities or reports containing sensitive security details
must not be filed publicly. Follow [SECURITY.md](SECURITY.md) instead.

Support is provided on a best-effort basis; a particular response time or
resolution is not guaranteed.
