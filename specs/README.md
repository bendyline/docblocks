# DocBlocks proposal specifications

This directory is for community-authored specification and prompt proposals.
DocBlocks does not accept source code contributions.

Each proposal should be a standalone Markdown document that explains:

- the problem or opportunity;
- the requested outcome;
- a suggested specification, prompt, or set of requirements;
- examples that show when the request is satisfied; and
- important constraints, edge cases, or compatibility considerations.

Use a short, descriptive filename such as `improve-pdf-table-layout.md`. A pull
request must contain only the proposal document and is governed by the
submission terms in [CONTRIBUTING.md](../CONTRIBUTING.md).
