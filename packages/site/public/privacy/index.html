Privacy · Updated July 14, 2026

Local-first means your documents stay under your control.

DocBlocks does not require an account and does not send the documents you edit to a DocBlocks/Bendyline server. Storage and network behavior depend on the surface and features you choose, as described below.

Documents in the web editor

Browser workspaces are stored on your device using browser storage. When you choose a local folder through the browser’s File System Access interface, DocBlocks can access only the handles you grant and the browser can ask you to renew that permission. Documents, media, revisions, and workspace metadata are used to provide the editing features you request.

Browser storage can be cleared by you, by browser settings, or sometimes by the browser under storage pressure. DocBlocks therefore offers backup and persistent-storage controls, but you remain responsible for keeping copies of important work.

Desktop, VS Code, and CLI files

The desktop app works inside folders you explicitly register. The VS Code extension edits the workspace documents opened by VS Code. Direct CLI commands use the filesystem authority of the process that you run. The MCP server begins without filesystem authority unless you start it with explicit read or write root grants.

Offline files and preferences

The web app installs a service worker and caches application code, fonts, and interface assets so the editor can work offline. Theme choices, workspace descriptors, dismissed notices, and similar device-local preferences may be stored by the browser. DocBlocks does not include advertising or behavioral analytics scripts.

Website hosting

DocBlocks.com is delivered through GitHub Pages. GitHub states that a visitor’s IP address is logged and stored for security purposes when a GitHub Pages site is visited. That hosting activity is governed by the GitHub Privacy Statement.

External links and issue reports

Links to GitHub, npm, Bendyline, or other external services are governed by those services’ policies. If you choose the DocBlocks issue-report link, your browser opens GitHub with a prefilled report containing the date, DocBlocks version and surface, and browser user-agent string. Review the report before submitting it. Document contents are not inserted into that report automatically.

Questions and corrections

For a privacy question or a correction to this page, open an issue in the DocBlocks repository. Do not include private document contents or credentials in a public issue.

DocBlocks is free open-source software in beta, by Bendyline.
