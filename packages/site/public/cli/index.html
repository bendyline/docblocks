  • Render documents as MP4 video

  • Parse Markdown, list themes, and refresh workspace catalogs in scripts

You decide what it can touch

Run it yourself, or hand it to an agent.

Commands you run read and write files like any other command-line tool. The MCP server starts with no access to your files: it holds results for the session and writes to disk only when asked to save, inside folders you allowed when you started it.

Build and preview

Turn a folder of Markdown into standalone web pages, or preview it on a local server that serves only supported file types from inside that folder.

Convert and render

Convert one source into Word, PowerPoint, PDF, HTML, DBK, and other supported targets, or render Markdown and imported documents as MP4 or GIF.

Work with AI agents

Agents can convert text or Markdown, inspect and preview the result, and compare versions. They read and save files only in the folders you grant.
