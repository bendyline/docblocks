Direct when you want it, bounded when you need it

One toolchain, two authority models.

Direct CLI commands use the invoking process’s filesystem authority and write their documented outputs. MCP starts with no filesystem grants, keeps results as temporary session artifacts, and materializes a file only through an explicit save operation.

Build and preview

Recursively turn Markdown into standalone HTML or serve a constrained local preview with contained asset reads and an allowlisted set of file types.

Convert and render

Convert one source into Word, PowerPoint, PDF, HTML, DBK, and other supported targets, or render Markdown and imported documents as MP4 or GIF.

Work with AI agents

Inspect, validate, preview, compare, and convert through strict MCP tools. Explicit root grants remain separate from artifact creation and durable output.
