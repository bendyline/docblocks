One editor, native capabilities

A desktop workflow without document lock-in.

The desktop renderer uses the same DocBlocks shell as the web app, then adds a narrow, security-conscious bridge for native folders and operating-system features. Your document remains Markdown whether you open it in DocBlocks, Git, a terminal, or another editor.

Work in real folders

Grant only the workspaces you want DocBlocks to use. The desktop app reads and writes inside those registered roots instead of hiding files in an application database.

Write three ways

Move between rich visual editing, raw Markdown source, and Play views for documents, slideshows, pages, and video-oriented presentation.

Export from the same source

Turn one Markdown document into PDF, Word, PowerPoint, HTML, and other supported formats while keeping the original readable and version-control friendly.
