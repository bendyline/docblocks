Import and export

What DocBlocks opens and exports

HTML ZIP, EPUB, MP4, and GIF are export-only; every other format opens as well as exports. AI agents can ask the DocBlocks MCP server for this list with list_formats, and the CLI reference covers every option.

Format Import Export Typical use
Markdown (MD) Yes Yes Portable editable source
Word (DOCX) Yes Yes Business documents and review

DocBlocks bundle (DBK) Yes Yes A zip file that contains markdown plus media assets

Visual export

Export common document formats, EPUB, and MP4 video from the web or desktop editor without leaving your document. Animated GIF comes from the CLI and MCP server, which use the FFmpeg installed on your computer.

Batch conversion

Use the CLI to convert a document into one or more formats with a single command.

Agent workflows

AI agents convert through the MCP server, check how faithfully each format kept the content, and save only the results you choose.
