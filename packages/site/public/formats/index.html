Supported formats

DocBlocks opens and exports the formats below. Some can be opened and exported; others are export-only. All of them work today.

Open the editor Use the CLI

Make Word documents, PDFs, slide decks, web pages, e-books, DBK bundles, and video from one Markdown file. Markdown stays the file you edit.

What DocBlocks opens and exports

HTML ZIP, EPUB, MP4, and GIF are export-only; every other format opens as well as exports. The web and desktop editors export directly to every format marked Yes; Excel, CSV, DBK bundles, and GIF export from the DocBlocks CLI and MCP server. AI agents can ask the DocBlocks MCP server for this list with list_formats, and the CLI reference covers every option.

From the editor

Export common document formats, EPUB, and MP4 video from the web or desktop editor. Spreadsheets, CSV, DBK bundles, and animated GIF come from the CLI and MCP server, which use the FFmpeg installed on your computer for GIF.

From the command line

Use the CLI to convert a document into one or more formats with a single command.

From an AI agent

AI agents convert through the MCP server, check how faithfully each format kept the content, and save only the results you choose.
