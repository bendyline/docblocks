DocBlocks for VS Code

Open .md files as visual documents inside VS Code. You keep VS Code’s file explorer, tabs, source control, and theme. DocBlocks adds visual writing, previews, pictures, and export.

Extension and setup guide See all the apps
  • Default rich editor for Markdown files
  • Write, Source, and Slideshow views
  • VS Code-native tabs, themes, and file explorer
  • Optional CLI and MCP setup guidance

How it works

Open a Markdown file visually when you want a document view. Save the usual way, with File → Save or Ctrl+S / Cmd+S.

Open Markdown visually

Install the extension, then open a .md file. If it opens as text, right-click the file and choose Open in DocBlocks, or run DocBlocks: Open Editor from the Command Palette.

Edit the source

Switch to the Markdown source at any time. The file still works with GitHub, static-site tools, other editors, and AI coding agents.

Set up the CLI and MCP server

Run DocBlocks: Open DocBlocks Tools (CLI+MCP) Setup to install the CLI in your workspace and configure its MCP server. The setup grants access to the current workspace; edit .vscode/mcp.json for narrower roots.
