DocBlocks for VS Code

Give every Markdown file a richer editing surface.

Open .md files as visual documents without leaving your workspace. VS Code keeps its file explorer, tabs, source control, and theme; DocBlocks supplies visual writing, raw source, Play views, media, and export controls.

Plain Markdown underneath

A document editor that respects the IDE around it.

DocBlocks deliberately uses a chrome-less editor webview in VS Code. Your project tree, editor tabs, save behavior, and external file changes stay under VS Code’s control, while DocBlocks focuses on the document itself.

Open Markdown visually

Make DocBlocks the default editor for .md files or use “Open in DocBlocks” only when you want the rich document surface.

Keep source close

Switch to raw Markdown whenever precision matters. The same source remains usable by GitHub, static-site tools, other editors, and AI coding agents.

Add tools when needed

The Setup pane can add the local DocBlocks CLI to a workspace and register its MCP server without granting filesystem roots automatically.
