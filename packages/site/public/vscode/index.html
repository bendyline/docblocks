Plain Markdown underneath

A document editor that respects the IDE around it.

Keep your project tree, editor tabs, keyboard shortcuts, and source control. Open Markdown visually when you want a document view, and save with VS Code’s usual File → Save or Ctrl+S / Cmd+S.

Open Markdown visually

Install the extension, then open a .md file. If it opens as text, right-click the file and choose Open in DocBlocks, or run DocBlocks: Open Editor from the Command Palette.

Keep source close

Switch to raw Markdown whenever precision matters. The same source remains usable by GitHub, static-site tools, other editors, and AI coding agents.

Add tools when needed

Run DocBlocks: Open DocBlocks Tools (CLI+MCP) Setup to install the CLI in your workspace and configure its MCP server. The setup grants access to the current workspace; edit .vscode/mcp.json for narrower roots.
