# Proposal: Self-Service Returns Portal

**Prepared by:** Customer Operations
**For:** The leadership team

## The problem

Customers who want to return an order must email support, wait for a reply, and then print a label we send them. Last quarter, returns made up 31% of all support emails, and the average return took 4.5 days to start.

## What we propose

We propose a returns portal on the website where customers choose the items to return, pick a reason, and print a prepaid label immediately. Support staff would only handle exceptions, such as damaged items.

## Timeline

The portal would be built in two phases. In phase one (July and August), we would build the portal for orders shipped within the country. In phase two (September), we would add international orders.

## Budget

The build would cost $48,000 in contractor time. Label printing through our carrier adds about $0.40 per return, which is less than the staff time each emailed return costs today.

## Expected results

We expect the portal to cut return-related support emails by at least half and to let customers start a return the same day. Two risks could delay this: our carrier's label service has not been tested at our volume, and the warehouse system needs a change to accept portal returns.
