# Spanish: ser vs estar

Both mean "to be". Ser is for what something is; estar is for how or where it is. (Mnemonic: DOCTOR for ser, PLACE for estar.)

## Ser: identity and permanent traits (DOCTOR)

- Description: "Mi hermana es alta."
- Occupation: "Soy ingeniero."
- Characteristic: "El cielo es azul."
- Time and date: "Son las cinco." "Hoy es martes."
- Origin: "Somos de Chile."
- Relationship: "Ella es mi prima."

Also: material ("La mesa es de madera"), possession ("El libro es de Ana"), and where an event takes place ("La fiesta es en mi casa").

## Estar: states and locations (PLACE)

- Position: "El libro está en la mesa."
- Location: "Estamos en Valencia."
- Action (progressive): "Estoy estudiando."
- Condition: "La sopa está fría." "Estoy cansado."
- Emotion: "Está contenta hoy."

## Conjugation (present)

| | ser | estar |
| --- | --- | --- |
| yo | soy | estoy |
| tú | eres | estás |
| él/ella | es | está |
| nosotros | somos | estamos |
| vosotros | sois | estáis |
| ellos | son | están |

## Adjectives that change meaning

- ser aburrido = to be boring; estar aburrido = to be bored
- ser listo = to be clever; estar listo = to be ready
- ser malo = to be bad (character); estar malo = to be sick or spoiled
- ser rico = to be wealthy; estar rico = to taste delicious
- ser vivo = to be sharp; estar vivo = to be alive

The note-to-self from class: when stuck, ask "is this a trait or a current state?" Most of the time that sorts it.

## Common mistake

"Estoy de acuerdo" (I agree) uses estar. And "Es casado" is wrong where "Está casado" is right, because marital status is treated as a state. See the separate notes on preterite vs imperfect for the past tenses.
